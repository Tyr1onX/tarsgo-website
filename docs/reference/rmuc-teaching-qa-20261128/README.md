## 移动对比

原始记录见 [movement-headless.json](movement-headless.json)。使用独立 Chrome headless、CDP 实际键盘/鼠标事件、同一窗口 1184×800，RAF 回调按最小间隔 0/50/100ms 门控，记录实际 WebGL render 调用的相机坐标、首个移动帧延迟、帧间隔与 render CPU 调用耗时（不等于 GPU 完成时间或完整帧总耗时）。每组约 1s 按键，基于按键释放后真实呈现帧计算距离。实际帧率由 intervalMs 计算；不是宣称固定 60/20/10 FPS。历史 commit e64cc4a 临时注入仅用于读取 renderer 的观测钩子；基线 2196687 使用现有 DEV QA 钩子，修复版同样使用 QA 钩子。三个工作树均未修改裁判规则。单次样本不代表性能统计置信区间。

| 模式 | 基线正常 / 低帧率距离 | 修复正常 / 低帧率距离 |
|---|---|---|
| 场外控制区 | 1.94 / 0.66 m | 2.20 / 2.20 m |
| 自由探索 | 1.94 / 0.66 m | 2.20 / 2.21 m |
| 自由飞行 | 5.00 / 2.10 m | 6.01 / 6.02 m |
| 历史自由飞行 | 5.30 / 1.80 m | — |

70px 鼠标拖动前后均为 14.04°，低帧率仍有呈现延迟。机器人在比赛准备阶段的单次移动对照仍存在低帧率限制，且反向测试可能受到碰撞/驱动加速度影响，不据此断言正式比赛速度。比赛运行中的固定步长裁判、机器人运动和输入队列没有修改，前哨实践实测成功。完整登录、保存与退出重入由更新后的现有浏览器集成测试覆盖，尚需 CI 实际结果。
