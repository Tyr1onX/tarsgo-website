## 第二轮素材规范
- 原生单格 128×112 像素，按 64×56 世界像素绘制（与现有 2 倍画布精度一致）；八方向列，四个底盘滚轮相位行及一个独立上部机构行（1024×560 图集）；原地面锚点 (32,39)，原占地半径 1.23 格不变。画布最近邻缩放；不通过放大世界实体展示细节。
- 底盘按实际运动朝向选择八方向，云台使用独立朝向；底盘长轴与上部机构的局部参考轴相差 90°，渲染端仅对底盘方向应用偏移。轮组相位由累计位移决定，停止时保持最后相位。
- 线稿相对轮廓用于压低底盘、缩短整体高度、区分中央轮与端部双滚轮、外露低矮框架、斜板与长水平上部机构；顶部与背面仍是推断。使用原环境的低饱和金属、左上光照和深色像素边缘。配色不代表真实机器人涂装。
- 训练场全图 CAD 是 Z-up；离线生成采用现有三维场景同样的 -90° X 轴变换。独立基地模型已经是 Y-up，不重复旋转。新增堡垒掩体来自 `red-fortress_0_source_4059143_0`，用于两处微缩空间障碍。所有图集仍为离线 PNG。
- 审阅标准：同时检查正常探索视角、接管视角和连续运动，确认本机线稿对照图；不能仅凭八方向图集认定实物结构准确。首台已确认；新增机型仍须单独审阅。
