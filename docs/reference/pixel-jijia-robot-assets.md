- 过洞步兵：用户提供的 `线稿.zip` 内 `果冻（立头）.pdf`（SHA256 前缀 `5e8a1ea1acf8e5ed`）。源图标题为「过洞哨兵总装配.SLDASM」；游戏暂按指定名称「过洞步兵机器人」。仅一个正投影视图，未获得真实 CAD、尺寸与背面资料。像素稿保留低矮底盘、中央可见大轮、两端窄滚轮、斜侧板、水平上部导轨和竖立头部；隐藏轮组、另一面、深度、色彩与占地为视觉推断，不是可制造模型或精确 CAD 复原。2026 照片和现有三维机器人是不同来源的参考，不冒认为该 CAD。
