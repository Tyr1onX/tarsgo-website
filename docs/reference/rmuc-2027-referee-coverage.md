## 能量机关源面审计（2026-11-24）

同一已审阅原始STEP层级，提取十条灯臂的圆面，面积均74506.01 mm²，直径308mm。红侧源面ID：269478、316135、362689、409085、455737；蓝侧：502389、549041、595693、642099、688761。中心直接从STEP质心测得。现有GLB无需重建，实际圆心正面射线首先命中约1.7mm前的蒙皮；允许3mm平面误差并且判定300mm有效圆，禁止背面与灯臂其他表面计分。三个旋转姿态共30次真实模型圆心射线均验证命中。已复核图5-17的十环直径30、60、…、300mm，径向15mm等分并非猜测；毫米边界取外侧环为仿真约定。

## 步兵经验与性能（2026-11-24）

按§5.5表5-14至18实现已支持的射击、实际伤害、击毁及机关经验来源。击毁奖励使用本次伤害前的攻击者等级，不能获经验的哨兵17mm伤害按照存活步兵平均值分配；42mm暂无能获该类弹丸经验的机器人。默认血量/冷却优先，真实装配未完成前按表5-12限制5级；保留原经验总数以便未来真实装配解锁。死亡保留经验、实际等级参与复活价格。跨越、飞镖、人工或离线伤害来源及装配等级尚未接入；不将此子集宣称为完整§5.5。
