## 基地源面审计（2026-11-24）

对 motion-reviewed STEP 的 base/covers/cover-0..2 与 base/fixed/source-remainder 共 11832 个源面进行原始实体/平面及颜色检查。三块移动护甲各有一个 10276.56 mm² 红色长条面（STEP #4295960、#4334742、#4373580）；不能凭红色或面积直接认定其为六块正式检测面。固定余部在局部竖直 y=400–850 mm 内无面积≥3000 mm²且质心落在该高度范围的平面。六块有效检测面的源实体、关闭/展开后遮挡和机械轨迹仍须逐一确认；暂不伪造命中区域。

继续核查 base/dart-target/carriage（2014源面）与 rail（2965源面），覆盖全部16811源面。两者在相同高度范围没有质心位于其中且面积≥3000 mm²的平面；固定余部此范围最大平面1345.76 mm²。三个 module backing shell 平面 #4652734/#4682612/#4712490 均16851.67 mm²，质心高度867.29 mm、法向竖直分量0.88701，不是图4-12中所示的六个独立竖向受击模块。以上不是源几何绝对缺失证明；已取得资料尚不能唯一绑定六块检测面。图4-11/12仅提供闭合/展开外形，未确认真实连杆运动或遮挡。删除整座基地总成 target 标签，实际完整场景射线回归确保两队闭合、半开、展开状态的外壳仍阻挡弹丸但不扣血。保留独立裁判端 base 伤害与胜负逻辑供后续绑定，不伪造模型或检测面。

## 步兵经验与性能（2026-11-24）

按§5.5表5-14至18实现已支持的射击、实际伤害、击毁及机关经验来源。击毁奖励使用本次伤害前的攻击者等级，不能获经验的哨兵17mm伤害按照存活步兵平均值分配；42mm暂无能获该类弹丸经验的机器人。按表5-17/18赛前接管步兵可选择血量/功率优先与冷却/爆发优先，开赛锁定、默认血量/冷却优先；升级使用对应表值，真实装配未完成前按表5-12限制5级；保留原经验总数以便未来真实装配解锁。死亡保留经验、实际等级参与复活价格。跨越、飞镖、人工或离线伤害来源及装配等级尚未接入；不将此子集宣称为完整§5.5。

## 底盘功率（2026-11-24）

按§5.1.4与表5-16/17实现60J缓冲、10Hz功率差积分和超限5s断电；按§5.3.2付费复活4s双倍功率上限200W。功率提升有独立截止时间，不随3s无敌结束而提前失效。重装50W、半自动哨兵60W、默认血量优先步兵45W起且每级+5W（现有等级上限5）。

当前为运动学训练模型：正常运动命令按功率上限、Shift加速按2倍需求、静止按0W；速度按功率平方根比例计算。没有实际电机转矩/电流数据，不能将该需求估算视为正式物理模型。哨兵姿态增益由表5-28统一结算。Ego Lite实际浏览器接管步兵，合成Shift+W键盘事件触发60J耗尽，显示底盘断电5s；松键后恢复60/60J、45W。

## 半自动哨兵姿态（2026-11-24）

按§5.7.2、表5-28开局移动姿态、5s切换冷却，累计同姿态超过180s衰减；强化时间计入对应普通姿态累计，每种强化独立15s，额度耗尽自动退回普通姿态。进攻强化清热且不增加热量，普通/衰减3/2倍冷却，功率减半；防御强化99%、普通50%、衰减25%，功率减半、冷却1/3；移动强化200W、普通1.5倍、衰减1.2倍，冷却1/3；进攻/移动25%易伤，同类取最高，与其他防御按手册相减。整数用四舍五入，未明确复活期间计时、自动退回的切换冷却，当前仅存活累计、自动退回不新增冷却。功率提升与已有付费复活同类取最高作为训练约定。半自动指挥操作免费，不冒充全自动哨兵指挥收费。

Ego Lite本地实际加载场地，QA只将自由视角放在7号哨兵可接管位置，实际接管/开始/进攻/强化按钮验证：移动90W、进攻30W、5s切换禁用与恢复、强化进攻15s；截图 /tmp/rmuc-sentry-boost.png。临时摆位钩子已移除；180s和强化累计边界由裁判测试覆盖。
