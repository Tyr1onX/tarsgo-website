# 运行保障与连接池观测

服务器使用显式 http.Server：请求头限时 5 秒，空闲连接 60 秒；不对整个上传、下载或导出套用统一读写短超时。数据库连接建立限时 5 秒；长查询的 read/write deadline 仍保留给后续分类预算。

SIGTERM/SIGINT 停止接收新请求，最多等待 8 秒让进行中的请求完成，超时关闭连接并返回错误。8 秒位于 Compose 默认 10 秒停止期限内。请求 context 不直接绑定退出信号，避免正常排空时提前取消数据库事务。后台维护在退出信号后取消，数据库连接在排空后关闭。

每分钟记录进程级连接池 open/in_use/idle/max_open，以及该分钟 WaitCount/WaitDuration 增量。不输出 DSN、SQL、用户 ID 或业务内容，不把全局计数当单请求统计；下一步按实际等待量决定容量，未上调连接数。

真实 TCP 测试覆盖信号后的活动请求正常完成，以及超过退出预算的请求被关闭；另验证 DSN 只限制连接建立而不限制长读写。本地后端全量测试、vet 和 serverruntime race 测试通过。无前端/导航请求/资源变化，无 schema 变化；未做生产时延或吞吐声明。

## 只读数据核验

2026-11-03 对生产执行已有只读核验 SQL（READ ONLY 事务，每条上限 15 秒，最终 ROLLBACK），未读正文、个人标识或凭证。MariaDB 11.4.13，schema v45：周报 16 条、重复用户周 0、空组别 0；历史面试记录 338 条；能力来源仍有 1 条引用。招新历史字段仍有数据，不能直接删列或删表。周报唯一键可进入恢复数据/隔离库演练，读时无重复不等于未来写入天然安全。

此检查通过现有运维连接在数据库容器执行，未创建账号、修改权限或持久化数据。使用只读副本/恢复备份仍是更大规模核验的优先路径。请求分类超时、每请求 SQL 次数、前端冷热/P95、历史 schema 演练未由本 PR 完成。
