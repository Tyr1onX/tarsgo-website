# 周报每人每周唯一约束

生产只读核验（2026-11-03，schema 45）16 条周报、重复用户周 0、空组别 0。迁移 46 使用固定 DDL 新增 `uk_weekly_report_user_week(user_id, week_start)`，不依赖当前 model AutoMigrate，以免历史迁移提前应用新约束。

先查询重复组数量；发现重复立即失败并保留全部历史。ALTER 本身再次原子验证约束，检查与执行之间如出现冲突也失败，不删除或覆盖记录。已有同名索引必须与预期列顺序/唯一性一致，否则停止。保留旧索引和 users 行锁，现行应用更新仍采用已有串行 upsert。

隔离 MariaDB 11.4 验证旧表 NULL 组别重复拒绝且历史不丢、无重复后迁移及重复执行成功、相同用户周的空组/跨组新插入均拒绝、正文保留。专用套件 17 个测试/子测试通过、零跳过；后端全量测试/vet 通过。CI 空库迁移路径还需通过门禁。
