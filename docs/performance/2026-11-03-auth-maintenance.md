# 认证维护退出请求路径

登录、账号列表和续期不再顺便清理所有过期记录。服务器启动后异步执行维护，此后每小时执行；每个事务最多选择 500 个过期账号容器及 500 个无引用旧会话，总轮次有 30 秒 context 时间预算。失败写日志并留待下一周期，不阻塞正常身份读取。

保护 API 仍逐请求验证账户状态、会话过期和撤销；清理不是权限生效的前提。保留仍被有效账号容器引用的过期会话、保留期内的无引用会话和活跃会话。容器选择带行锁，删除会话时重新检查引用和过期条件。

本地全量后端测试、vet 通过；auth/middleware race 测试通过；MariaDB 合成套件新增维护回归，验证旧孤儿/失效容器会话被清理，活跃容器引用、保留期和有效会话保留。实际数据库套件 16 个测试/子测试通过、零跳过。

未改变认证期限和角色规则；无前端或数据库结构改动。未进行生产验证。后台清理仍消耗数据库资源，多实例可能各自调度，但操作幂等且批次有限；无需为当前规模新增队列系统。请求级超时及生产连接池等待监控需结合实测另行配置，不用全局短超时破坏上传或导出。
