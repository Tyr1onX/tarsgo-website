# 工作台独立区域更新

周报、作业和请假摘要并发发起后，各自完成即发布状态，不再等最慢请求才统一显示。保留按账号/角色/组别隔离的旧快照；旧请求通过 generation 校验不能写回缓存。未返回的区域继续显示读取状态，失败保留旧数据并提供重试，不提前显示“没有待办”。

每次更新构造新快照，避免后续完成或失败修改已经发布的状态。deferred promise 行为测试覆盖快请求先显示、慢请求仍 pending、失败保留旧数据以及后续成功不覆盖错误。测试曾捕获 await 前展开旧快照导致并发覆盖的问题，现已改为 await 完成后才合并。

前端完整测试 336 项：333 通过、3 跳过、0 失败；typecheck 与生产构建通过。浏览器使用本地合成超级管理员确认工作台本周待填写、请假可办理及跳转管理页面；合成账号没有技术组，管理页相应权限提示正常。无生产验证。
