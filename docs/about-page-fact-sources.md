## 明确保留的待核实边界

- 当前各组实际人员配置、负责人和管理岗位：岗位目录 `knowledge/organization/team-role-catalog.md` 明确不是当前组织结构表；页面不展示人员与岗位名单。
- 每个组别的专属照片：现有照片可以展示团队协作场景，但缺少逐张确认组别归属的资料；页面不做组别照片映射。
- 训练营、校内赛、老队员分享的当前执行频次：历史资料包含公开课、实践与交流记录，也包含赛季计划；页面不将它们描述成每年固定制度。
- 赛季口号与长期队训：2025 文化规划中的赛季口号只属于当届资料，本页不引用为永久主张。
