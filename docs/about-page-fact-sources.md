## 照片与地点边界

- `/assets/images/Preparation_for_competition/preparation-01.webp` 与 `/assets/images/Daily/daily-08.webp` 中可见吉甲大师标识，适合呈现带有团队标识的工作空间。页面以可见内容为准，不把图像本身当作地址证明。
- 当前仓库、公开队史和照片记录没有吉甲基地的可信经纬度，也没有带有经核对 GPS/EXIF 位置的基地照片。基地门牌或联系人地址不能直接换算成未经核对的坐标。
- 因此，本版不实现“沙尘坐标”彩蛋。后续需要经团队确认的基地坐标，以及明确拍摄于该处并获准使用的照片；坐标编码和视觉效果应在核实后单独设计。
- 页面没有引入虚构队史，也没有改变首页六张照片的沙画显影实现。
