# AI 沙龙报名按钮点击统计验收

基于最新 main `00b9fae` 创建独立分支，承接 Issue #317 完成后的用户追加功能。既有可读性优化与「像素吉大」文案已经通过 #318/#319 上线；本次增加后台累计点击统计。

## 行为与数据

- 详情页原官方报名链接及完整渠道参数保持，左键、键盘 Enter 与中键激活时异步 POST；不等待统计响应，不改变原生新标签页跳转。页面加载、刷新及右键菜单不会累计。
- 复用活动表，迁移 54 增加默认 0 的无符号计数列；不记录访客身份、IP 或个人资料，不补造历史次数。
- 仅已发布、线上且有合法首行 HTTPS 报名入口的活动接受计数；复用同源校验，匿名可点击。事务内与编辑使用相同活动行锁，数据库原子递增，编辑时保留服务端计数，忽略客户端传入值。
- 公开列表与详情 API 不返回次数。仅超级管理员原活动管理列表显示「报名按钮点击 N 次」，刷新页面读取最新值，无新增公开 UI 或轮询。
- 记录的是成功到达服务器的按钮激活次数，可重复累计，不代表独立人数或实际完成报名；统计失败仍可继续报名。
