# 社区成员主页简化验收

## 改动

- 姓名和介绍复用 input / textarea 与原接口，原位显示，Enter 或失焦保存、Shift + Enter 换行、Esc 取消；中文输入法选字不提交。未改不请求，以同步锁避免并发提交；失败保留输入并显示字段错误。
- 概览使用已有组别、岗位、有效加入时间、统计和代表徽章。删除近期活动展示、数据结构及后端帖子/回复活动查询。
- 成员徽章只使用主页接口的一套当前有效徽章网格；说明、日期和当前等级动画重播收进弹层。移除额外个人徽章请求、旧组件、升级历史/进度/贡献陈列及无用样式。管理员贡献管理、撤销审计与原有规则继续使用管理接口。
- 无新依赖、无数据库迁移、无新增统计接口。保存姓名仍通知账号资料缓存和社区列表；介绍与代表徽章仅提交各自字段，避免互相覆盖。

## 真实浏览器验收

使用实际 Chrome、编译后的前后端、独立的本地虚构账号及数据库 `tarsgo_profile_browser`。网络故障用浏览器拦截单次保存返回 503；输入法用真实浏览器键盘事件的 `isComposing` 和 `keyCode=229` 验证，未进行操作系统中文输入法人工选字。

- 姓名点击编辑，字体、颜色、行高、位置与宽度不变；Enter / 失焦保存、未改不请求、Enter 与失焦重叠只一次请求，Esc 后不保存。
- 介绍原位编辑；Shift + Enter 实际插入换行；Enter / 失焦保存、Esc 取消，空介绍、多行和长文本在手机宽度下编辑前后尺寸一致。
- 两字段的中文选字保护、失败保留输入/错误提示/重试通过。姓名失焦与介绍 Enter 并行保存不覆盖字段。
- 姓名保存后导航账号按钮、社区帖子作者和主页一致；其他成员主页无姓名/介绍/头像编辑，普通成员访问徽章管理 API 返回 403。
- 用真实发帖、回复和点赞验证统计为 1/1/1；组别、组长与加入时间一致；当前组织岗位可见，缺失字段不显示。概览无近期活动或帖子/回复列表，只有一条 XP 进度；独立帖子和回复标签可浏览。
- 管理员真实授予、撤销、再次授予；成员页只显示当前徽章，撤销后徽章及代表徽章消失，管理页保留撤销记录。代表徽章保存、说明/日期弹层、Esc 焦点恢复及解锁重播通过。
- 向成员页响应额外注入 `isEarned=false` 的历史徽章，前端防御过滤通过；不再发起旧的 `/api/me/co-builder-badge` 陈列请求。
- 管理员帖子设为/取消精华通过。1440、390、360 宽度及明暗主题检查通过，无横向溢出；移动端介绍编辑、徽章弹层和键盘操作正常；无浏览器脚本错误。
