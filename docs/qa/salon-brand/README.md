# 极简官网导航与 AI 沙龙品牌主页验收

2026-11-03，基于最新 main `b4eb99a` 开发；本记录仅描述本轮实际执行的本地验证。生产部署与线上只读验证在 PR 后续记录。

## 范围

- 官网 Navbar 删除公开导航数据、桌面列表、汉堡菜单、移动菜单状态、断点焦点迁移及其专用样式。桌面和手机复用一个账号菜单，保留键盘导航、Escape 返回焦点、点击外部关闭和原有权限判定。
- 顶栏保留 Logo 返回首页、明暗切换与系统主题偏好、登录或头像入口。头像菜单仅有我的主页、按原权限显示的工作台与管理后台、切换账号和退出登录。注册仍从登录页进入。
- `/programs` 使用路由 replace 跳转 `/programs/ai-salon`，沙龙子路由全部保留；首页八个入口、低空微专业独立页面与摄影卡片保持原状。
- 沙龙主页以原创 SVG 构造线与实体几何表现从想法到作品；活动卡片复用原 API，无海报时复用该图形，有海报时完整展示。无活动时保留品牌内容与紧凑筹备提示。没有真实成果数据，不增加成果展示区域或管理功能。
- 详情页重排活动内容和报名信息，桌面双栏、手机单栏；时间、地点、截止时间与报名操作集中展示。仅调整前端呈现与样式，不改 API、后端、数据库、报名状态转换或权限。

## 实际检查

- `make frontend-test frontend-check build`（Node 22.23.4 / pnpm 9.15.4）：330 项，327 通过、0 失败、3 跳过；跳过项为原有 2024/2025/2026 照片源文件可用性检查。类型检查、前端生产构建及嵌入前端的 Go 构建通过。原社区编辑器的大分包提示仍在。
- `go -C internal/backend test ./service/aisalon ./router`：通过；不将普通运行中可选数据库测试的跳过声称为集成验证。
- 本轮真实 Chrome 浏览器使用生产构建及本机 MariaDB 独立库 `tarsgo_salon_brand_browser`，仅监听 127.0.0.1:8194，全部账号为 `salon-browser-*@tarsgo.test`。测试账号创建时间使用北京时间口径，避免触发既有历史账号兼容边界。没有写入生产数据库。
- 业务浏览器回归 14 组检查通过：创建/编辑/发布/删除、学号重复拒绝、报名、候补、两类取消、重新报名与候补排序、自动补位、扩容补位、提前关闭与重新开放、截止限制、签到一次、报名历史与资料快照、名单统计/筛选/真实 CSV 下载、匿名及普通管理员隔离。还比较了新社区账号报名前后的组别、角色、战队身份和工作台访问标记，均未获得额外权限。
- 28 组截图检查覆盖：无活动、有活动且无海报、有海报、匿名详情、已报名、候补、已签到 × 桌面1440/手机390 × 明暗主题。海报是浏览器拦截 `.test` 图片域返回的明确 TEST 图形，仅用于本地测试。人工查看代表截图确认层级、断行、海报比例与按钮状态。
- 导航浏览器：320/390/768/1440 × 明暗主题；390/1440 实际点击首页全部八个入口，匿名社区入口按原规则进入登录页。Logo 返回首页、旧页跳转、微专业独立页面正常。普通社区成员没有工作台和管理后台菜单；普通管理员及超管显示原有允许的个人入口，沙龙管理仍仅超管可进入。验证 Home/End/Escape、外部点击、切换账号参数与退出登录。两个浏览器脚本页面异常均为 0。

## 导航性能与边界

`navigation-results.json` 保存真实浏览器的路由提交、标题可见时间及逐项 API/资源耗时。官网→工作台和工作台→管理各采样4次；第1次标为首次样本，后3次通过浏览器后退在同一文档中复用路由与身份缓存。原有工作台预取仍在，所以首次样本不等于完全冷加载。独立文档冷加载单独记录。样本不足以给出有代表性的 P95，未做生产或改动前后性能对比。未出现 `/api/me` 重读的已加载样本仅说明该次观察复用了现有身份状态，不推断所有请求都命中缓存。

本次没有新增路由加载器等待或导航关键路径请求；沙龙主页仅异步请求既有公开活动列表。身份读取、报名资料请求与轮询沿用原实现。几何图形内联，无新增外部图片依赖、第三方 UI 库或高频操作流程。
