# 吉甲基地 · 每日通信：P1 实施说明

关联 [总规划 #66](https://github.com/Tyr1onX/tarsgo-website/issues/66)、[设计评审 #67](https://github.com/Tyr1onX/tarsgo-website/issues/67)、[功能 Issue #68](https://github.com/Tyr1onX/tarsgo-website/issues/68)。交互原型仍见 [P0 原型入口](../../prototypes/daily-signal/index.html)；正式体验从主导航的「吉甲基地」进入。

## 信息架构

- 官网以「了解吉甲、参与吉甲、管理吉甲」组织入口：首页保留战队专题内容和「吉甲基地」参与入口。
- `/base` 对游客公开并显示欢迎页；登录用户进入统一工作台的 `/dashboard/base`，查看每日通信签到终端、情绪状态与年度档案热力图。
- `/dashboard` 是各登录角色共用的工作台首页；每日通信、个人招新和按权限显示的管理功能都位于同一套导航中。
- `/daily-signal` 保留为兼容地址，连同查询参数和片段重定向至 `/base`，登录后再进入 `/dashboard/base`。未开放的规则竞技场、基地档案等不展示为可用入口。
- 账号切换沿用原有会话流程；工作台导航按当前角色过滤管理功能，管理 API 继续由服务端权限中间件保护。
- 首页空间划分、基地卡片视觉及后续扩展边界另见[吉甲基地信息架构说明](../gijia-base/README.md)。

## 产品边界

- 页面向所有人开放。访客可以浏览当年与往年的个人档案网格，但接口只返回空白档案，不展示任何真实账号的签到日期或情绪；登录后才能发送信号并查看自己的真实档案。
- 登录用户均可参与，不根据队员身份或角色过滤。请求身份只从现有 HttpOnly 会话解析；客户端不能传入目标用户 ID。
- 每日以服务端 `Asia/Shanghai` 日期为准，北京时间零点换日。账号与日期组成唯一键；并发第二次写入读取并返回已有记录，不新增行，也不覆盖其情绪。
- 情绪是可选字段。当天签到后先以只读回执展示；点击「修改状态」后才能编辑、保存或清空，避免误触造成已保存的错觉。
- 只允许本人查看自己的历史情绪。本人可删除历史情绪，删除只清空 mood 字段，签到日期继续保留。历史情绪修改和整日签到撤回目前不提供。
- 本期没有公共聚合、管理员查询、考勤、积分、连续签到、排行榜、组别比较或声音。

## 数据与接口

`daily_signals` 只保存用户 ID、北京时间日期、可空情绪和创建 / 更新时间；用户 ID 与日期有数据库唯一约束，并通过外键关联账号。日期按 `YYYY-MM-DD` 存储，避免依赖数据库连接时区。账号硬删除会级联删除个人信号；停用账号仍保留原档案。

| 接口 | 权限 | 行为 |
| --- | --- | --- |
| `GET /api/daily-signals?year=YYYY` | 可选登录 | 未登录返回空个人档案；已登录只按当前会话用户 ID 查询指定年和今日状态。响应禁止缓存。 |
| `POST /api/daily-signals` | 登录 | 用服务端当天日期幂等创建一条记录；`mood` 可为空。重复 / 并发请求返回已有记录。 |
| `PATCH /api/daily-signals/today/mood` | 登录 | 仅修改当前账号今天已存在记录的 mood；`null` 清空情绪，不创建签到记录。 |
| `DELETE /api/daily-signals/:date/mood` | 登录 | 仅清空本人过去日期的 mood；不删除签到行，不能以该接口清除今天或未来日期。 |

个人档案不经过管理端或聚合服务。页面在同标签账号切换时立即清空旧档案，取消旧读取请求并按新会话重新读取；跨标签切换后也会重新验证身份。网络失败时保留可重试入口；若发送请求已由数据库提交但响应丢失，重试受唯一键保护，不会覆盖已存 mood。

## 日期档案交互

- 热力图每列为一周、每行为星期，日期按真实自然日排列；签到方块维持单一暖金层级，未签到使用石墨 / 陶瓷细边材质，今天有细描边，未来日期弱化并禁用。
- 移动端首次打开定位今天所在周；滑动浏览历史不触发自动回位。「回到今天」主动切回当前年并定位今天。
- 键盘方向键按日或按周移动；触屏目标扩大到 24px，但内部方块保留 12px 材质尺寸。横向滚动限定在档案区域，不扩展页面宽度。
- 发送成功后使用短促的点亮与回执动画；`prefers-reduced-motion` 关闭平滑滚动并压缩动画。文案和成功状态不依赖动画完成。
- 日期详情将历史情绪与签到日期分开展示；删除历史情绪后仍显示金色签到方块和「没有保留状态」说明。

## 已确认的产品决策与待确认问题

**已确认并实现：**

- 使用范围为所有人；访客可浏览界面，登录后才能写入；每个登录账号隔离自己的档案。
- 日界线为服务器上的 `Asia/Shanghai` 零点。
- 当天可修改或清空自愿填写的状态，不增加第二条信号。
- 情绪仅本人可读；管理员与超级管理员不能读取其他人的情绪，也没有个人签到管理面板。
- 本人删除历史 mood 后保留签到日；历史 mood 不可修改。

**尚待产品决定，当前不实现：**

1. 日期与情绪的长期保留期限，以及账号注销 / 法定删除请求的处理口径。
2. 是否允许用户撤回整日签到（当前数据库和 API 只提供删除情绪，不删除日期）。
3. 是否有必要增加不含情绪、且不会反推出少数参与者的匿名基地聚合；当前没有聚合查询。
4. 如果未来允许修改历史情绪，需重新评估隐私提示、操作记录与历史状态的删除路径。

## 验收记录

本节记录独立本地验收环境的实际结果，不代表生产验证。

- 隔离环境：专用本地 MariaDB（端口 3317、数据库 `tarsgo_acceptance`）和模拟邮箱；使用 `test-user@tarsgo.test`、`test-admin@tarsgo.test` 等虚构账号。没有连接生产数据库。
- 后端：`make backend-test` 全部通过，包括服务、路由、权限、迁移和日期模型测试。针对虚构测试账号连续发送两次当日请求，均返回 HTTP 200、`created: false`，第二次提交的不同情绪没有覆盖原值；档案 GET 返回 `Cache-Control: no-store`。
- 前端：导航、微专业、进度、工作台、邮件模板、认证状态与每日通信七组测试全部通过（39 项）；React Router 类型检查和生产构建通过。
- 公共站点单测：本地稀疏检出缺少未纳入当前工作树的站点图片与图库 manifest，相关测试 18 项中 13 项通过、5 项因 `ENOENT` 失败（证书、组别 SVG、备赛图片与机器人图库资源）。这些资源不属于本次修改；完整文件集下的结果由 PR CI 确认。
- 运维与脚本：全部 `scripts/*.sh` 通过 `bash -n`；`scripts/test-production-ops.sh` 的清理、回滚、镜像保留、归档校验等检查全部通过。
- 真实浏览器：Chromium 153.0.8010.12。此前在 1440、1024、768、390、320 像素视口检查布局；本轮重新检查 1440 与 390 像素、两套主题、访客隔离、今日所在周默认定位、跨年切换、返回今天、方向键与历史状态。390 像素视口下文档宽 379 像素，页面没有横向溢出；今日签到格位于热力图可视区域。
- 帐号隔离：用 PR #73 的账号切换操作在虚构普通账号与管理员账号间往返；各自只见自己的档案。访客视图已确认 `sent` 格子为 0、历史情绪节点为 0。
- 隐私与删除：虚构账号的历史情绪删除后，签到日期仍出现在档案中；今日状态可以修改和清空。数据库行与热力图均保留签到日期。
- 减少动态效果：在 macOS「辅助功能 → 动态效果」临时启用「减弱动态效果」后，浏览器报告 `prefers-reduced-motion: reduce`，核心动画计算时长为 `0.00001s`，档案滚动为 `auto`；随后已恢复原系统设置。
- 生产部署：未执行。

### 基地工作空间与抖动回归（2026-10-16）

- 本次尝试在真实 Chromium 中复现“无人操作时页面反复上下跳动”。修改前桌面与移动视口各静置观察 20 秒，均未复现；因此没有证据确认一个能解释原报告现象的实际根因。
- 代码检查未发现 `ResizeObserver` 或页面级 `scrollTo` 的重复触发。首次定位今天的请求只消费一次，并只对热力图视口设置横向滚动。原方向键路径调用 `scrollIntoView`，可能把焦点滚动传播到页面；本次改为 `focus({ preventScroll: true })`，并只在热力图容器内调整 `scrollLeft`，同时避免对已处于目标位置的容器重复滚动。该路径修复了可确认的页面滚动风险，但由于未能复现原症状，不能断言它就是该自动抖动的根因。
- 修复后真实 Chromium 静置观察：桌面 1440×900、30 秒 / 30 次采样，`scrollY`、页面高度、热力图横向位置及档案纵向位置均保持不变；移动 390×844、重新载入并完成今日定位后，30 秒 / 30 次采样同样稳定，今日方块持续可见。修改前后均未观察到页面垂直抖动。
- 页面在 1440、390、320 像素视口下均无文档横向溢出；390 像素下首次定位今日成功。黑金、白金主题都已检查。访客档案保持空白；本地隔离库中的 `test-user@tarsgo.test` 与 `test-admin@tarsgo.test` 今日情绪不同，切换后各自只显示本账号数据；已在虚构管理员账号修改状态、切换至 2025 年并返回今天。
- 桌面侧栏通过 Space 键完成折叠和展开；移动侧栏打开后焦点进入「每日通信」，Escape 关闭并还原到导航按钮。`/daily-signal` 原链接的查询参数与片段均随重定向保留。
- 本轮自动化回归新增独立滚动 helper 测试：验证只在热力图内部滚动、无须位置变化时不重复滚动，并约束方向键路径不再使用 `scrollIntoView` 或页面级 `window.scrollTo`。测试和完整 CI 结果以对应 PR 检查为准。
- 验收使用独立本地 MariaDB 与虚构账号，没有连接生产服务；本轮未部署。
