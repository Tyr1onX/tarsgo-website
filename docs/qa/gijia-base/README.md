# 吉甲基地 · 信息架构与交互说明

吉甲基地是官网面向公众的参与空间。每日通信是目前唯一开放的基地功能；页面为后续真实可用的互动功能留出扩展位置，但没有不可用的占位入口。

## 三个空间

| 空间 | 承载内容 | 官网入口 |
| --- | --- | --- |
| 了解吉甲 | 战队介绍、团队历程、机器人、赛事荣誉、纳新与微专业 | 首页专题导航和现有栏目 |
| 参与吉甲 | 基地首页，以及基地当前开放的互动功能 | 主导航「吉甲基地」、首页基地入口卡片 |
| 管理吉甲 | 个人工作台、成员管理和后台事务 | 首页工作台入口、登录后的工作台导航 |

工作台继续保留「每日通信」快捷链接，便于现有用户直达；它不再是每日通信的主要归属。登录用户从首页进入工作台时，沿用现有角色默认路由；访客先登录，再进入默认工作台。

## 吉甲基地首页

- `/base` 对所有访客开放，复用官网主导航、主题系统与页脚。
- 页面说明基地的参与定位，并只呈现已开放的「每日通信」卡片。
- 每日通信仍使用既有 `/daily-signal` 地址；原链接可继续访问，页面可返回基地首页，主导航也将每日通信识别为基地空间。
- 基地入口不复制签到能力；签到状态、情绪隐私、北京时间与历史档案规则沿用[每日通信 P1 说明](../daily-signal/p1-implementation.md)。
- 黑金以深色表面、低饱和金色和细线表达仪式感；白金复用陶瓷白、石墨文字与香槟金。装饰克制，信息层级由标题、留白和材质区分。
- 小屏按单列呈现基地与工作台入口；导航可折叠；卡片整块可操作并保留键盘焦点轮廓。

## 后续扩展边界

1. 只在对应功能已具备真实页面和可执行操作后，才增加基地入口。规则竞技场、基地档案等未实现功能不以禁用卡片、虚构数字或「即将开放」形式展示。
2. 新功能归属基地时复用公共导航与主题，不另造一套登录、账户切换或全站入口体系。
3. 保持每日通信个人数据边界。未来的公共互动不可默认读取或聚合个人情绪，也不新增积分、考勤、连签或排行榜。
4. 继续将产品范围问题记录在具体功能 Issue；开发前确认访问范围、身份边界、数据保留与异常状态。

## 本轮浏览器验收

- 使用本地 Chromium 打开 `/`、`/base` 与旧地址 `/daily-signal`；确认主导航的「吉甲基地」链接、首页三个空间入口、基地每日通信卡片和返回基地链接均可见。
- 桌面 1440px 与移动 390px 检查黑金、白金主题和布局；移动端没有页面级横向溢出，首页专题卡片和基地入口按单列 / 双列断点正常呈现。
- 移动导航打开、通过键盘焦点到达每日通信卡片并用 Enter 导航成功；卡片显示可见焦点轮廓。
- 浏览器未连接本地认证 API，因此只验证了访客可浏览和认证失败提示；没有将该结果表述为真实账户登录验收。
