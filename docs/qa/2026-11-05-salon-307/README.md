# 第一期 AStudio 参与流程修正（Issue #307）

基于最新 main `c338648`。原后台可以更新正文和会议链接，但参与卡片仅有会议入口，无法将官方注册报名作为首要按钮，且“无需注册”易与讯飞账号准备混淆。因此仅作前端适配，未修改后端、数据库结构、认证或报名/签到服务。

## 修改

- 更新第一期现有 summary：依托 AStudio 官方创作活动，顺序为注册报名、安装准备、线上参与、创作与提交、交流分享；明确 45 分钟仅上手和初步创作，最终作品可会后完善。
- 线上正文首行的独立 HTTPS Markdown 链接可显示为参与卡片主按钮，仍由原活动内容字段维护，无新配置字段。完整 URL 不重新序列化，保留 ch 参数；正文不重复主按钮，列表摘要使用后续介绍。
- 本期主按钮“报名参与 AI 创作活动”；有主按钮时会议入口使用次要样式，不验证或拦截参赛报名状态。会议未提供时只有待公布文字。
- 官网免账号提示明确为“无需注册或登录吉甲大师官网”。线下正文及实名报名/签到路径保留；普通线上正文没有首行链接时保持原展示。
