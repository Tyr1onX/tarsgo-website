# TARS-Go 战队文化与队史资料

本目录归档战队文化建设与队史材料，保留资料成文时的语境。文档中的组织规模、岗位称谓、活动计划和口号均为历史记录，引用或对外发布前应由战队确认是否仍适用。

## 2023 年 12 月：战队文化建设

- 原件：[2023-12-jlu-tarsgo-culture.pdf](2023-12-jlu-tarsgo-culture.pdf)
- 编制单位：吉林大学 TARS_Go 战队
- 发布日期：2023 年 12 月
- 文档适用背景：RoboMaster 2024 机甲大师超级对抗赛

### 内容索引

1. 通过小组座谈、顾问及老队员访谈、队员问卷梳理队伍对赛事文化的理解。文档记载当时有 18 名正式队员参与座谈、8 名顾问或老队员接受访谈、21 名正式队员填写问卷。
2. 将赛事与团队文化概括为学术科技交流、工程师协作、大学生青春追求，以及人机协作和观赛互动。
3. 记录战队起源与当时的团队特点，包括跨校区协作、“金满堂”聚餐文化等。
4. 文档记载的价值观为“凝聚，齐心协力；突破，永无止境”，口号为“裹甲衔枚，负芒披苇”。
5. 提出一份按学年月份安排迎新、团建、文化分享、周边制作、赛前宣传和复盘等活动的执行规划。

### 使用说明

此处仅作历史归档。PDF 中的执行安排是当年提出的方案，不表示这些活动目前仍在执行，也不构成本次新任务。采用其中的介绍、数字或计划前，请先核对当前情况。
