# 硬件方向：把设计变成可靠的电路板

硬件方向的工作从读懂电路原理图开始，经过器件选型、PCB 布局布线、打样与调试，最终让板卡在机器人上稳定运行。

**学习顺序：** 原理图与 PCB → DC-DC 电源 → STM32 最小系统 → 主控板 → 独立完成一块板卡。各阶段对应[硬件组原始培养路线](?group=hardware)。

## 第一阶段｜读图、画图和检查

### 1. 熟悉设计工具

在组内使用的嘉立创设计软件中，认识原理图、封装、网络和 PCB 的关系。找一个简单电路，确认器件引脚与 PCB 焊盘之间的对应关系。

**动手练习：** 画一张含电源、连接器和指示灯的练习原理图，补齐器件标号与网络名称，转换到 PCB 并完成布局布线。

**完成判断：** 能从原理图追踪一条连接到 PCB，理解 ERC（电气规则检查）与 DRC（设计规则检查）各在检查什么。

### 2. DC-DC 电源模块

理解输入电压、目标输出、负载电流、转换效率及反馈网络。阅读所选芯片的数据手册，核对应用电路与关键器件参数。

**动手练习：** 整理一份电源模块的器件表和主要设计参数，按组内规范完成设计评审与检查。进入实际调试时，先确认连接、极性与保护措施，再按指导逐项测量输出。

**完成判断：** 能说清电源输入输出要求，并通过测量结果判断设计是否满足目标。

### 3. STM32 最小系统板

认识供电、时钟、复位、下载调试接口与基础外设引出。根据所用芯片的数据手册检查引脚连接、供电和去耦布局。

**动手练习：** 绘制最小系统原理图与 PCB，准备器件清单、制造文件和调试记录；打样后按组内流程完成上电检查和程序下载。

**完成判断：** 能解释每个关键电路的作用，并定位基础供电或下载连接异常。

## 第二阶段｜独立设计校内赛小车主控板

初级训练完成后，将主控、通信、电源和外部接口放在同一套设计中。

**建议按四步推进：** 整理功能和接口需求 → 画系统框图与原理图 → 完成 PCB 及规则检查 → 打样、调试并与电控联调。

**形成的成果：** 可追溯的原理图、PCB、BOM、版本记录和测试结果。板卡上的每一个接口都应能找到对应的说明。

## 第三阶段｜从复刻走向独立设计

冬令营后到分区赛前，选择组内认可的开源硬件项目，重点理解其供电、接口、布局和走线思路，再独立负责一个具体项目。

**动手练习：** 对比开源板卡与自己的方案，说明关键器件选择和布局差异；完成设计、打样、调试闭环，整理修改前后的问题与结果。

**完成判断：** 遇到板卡异常时，能从供电、信号、布局和软件接口逐步查找原因，并解释最终修改依据。

## 和软件方向怎样衔接

原始培养路线还提出学习软件组相关内容。与组内确认具体范围后，优先理解 STM32 程序下载、通信接口、外设驱动和软硬件联调，才能让自己设计的板卡真正投入使用。
