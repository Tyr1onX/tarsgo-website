# 电控方向：让机器人按预期工作

电控负责把传感器、电机和控制程序连接成可靠的机器人系统。你会从编写程序和驱动外设开始，逐步参与底盘、云台与整车联调。

**学习顺序：** C 语言 → STM32 外设 → 通信与电机控制 → PID 和 FreeRTOS → 整车联调与系统维护。各阶段对应[电控组原始培养路线](?group=electrical)。

## 第一阶段｜把程序运行在开发板上

### 1. C 语言与数据处理

先用小程序练习指针、结构体、内存布局和位运算。例如，用结构体保存电机的目标转速、实际转速与状态标志，再用按位运算读写状态。

**动手练习：** 编写一个程序，输入模拟的电机反馈数据，更新结构体并输出运行状态。修改输入后，观察输出是否符合预期。

**完成判断：** 能说明变量、指针与结构体的关系，知道如何定位数组越界、未初始化变量等常见问题。

### 2. STM32 与基础外设

依次练习 GPIO、定时器、中断、PWM、ADC 和 DMA。每次先确认引脚及外设配置，再验证实际输入、输出或采样结果。

**动手练习：** 在组内开发板上完成 LED 闪烁、按键中断、PWM 输出及 ADC 采样，记录每项实验的配置和观察结果。

**完成判断：** 能独立找到外设配置入口，解释中断与轮询的区别，并根据现象定位基础配置问题。

### 3. 通信与电机

了解 UART、SPI、I²C、CAN 各自适用的连接方式；结合组内设备认识电机、驱动器和反馈信号，理解开环驱动与闭环反馈的区别。

**动手练习：** 使用串口观察一组有固定格式的数据，标注字段含义；再在组内指导下完成电机的低速启动、停止与反馈读取。

**完成判断：** 能描述“控制指令 → 驱动 → 电机 → 反馈”的链路，遇到异常时先区分供电、连接、通信和程序问题。

## 第二阶段｜让控制更稳定

### 4. PID 与 FreeRTOS 入门

理解目标值、测量值、误差和控制输出。通过曲线观察比例、积分、微分参数对系统响应的影响；在 FreeRTOS 中练习任务创建、周期执行和延时调度。

**动手练习：** 使用仿真数据或组内测试程序对比两组 PID 参数的响应曲线，再安排两个周期任务输出状态信息。

**完成判断：** 能解释超调、振荡和稳态误差，知道实时任务为什么需要合理的运行周期。

### 5. 冬令营进阶

把程序拆分为驱动层、中间层、应用层，进一步学习任务调度、信号量、消息队列和互斥锁。

**动手练习：** 将一个混合在主循环中的功能拆成有明确接口的模块，并使用队列传递一组传感器数据。

## 第三阶段｜参与整车研发

校内赛后，按照原路线学习底盘运动学与闭环控制、姿态控制、摩擦轮及拨盘供弹逻辑、PID 参数整定和整车故障排查。

**建议从一条完整链路开始：** 选择一个底盘或执行机构功能，记录目标行为、输入与输出、测试现象和修改结果。联调时与机械、硬件等方向核对接口。

## 第四阶段｜独立负责一个模块

夏令营到正式队员考核阶段，进一步熟悉裁判系统、异常保护、看门狗与通信容错，并承担模块或车组的维护。

**形成的成果：** 模块代码、接口说明、调试记录和常见问题清单。下一位接手的人可以据此完成环境搭建、复现问题和继续迭代。
