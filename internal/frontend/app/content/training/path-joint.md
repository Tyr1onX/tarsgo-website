# AI 与视觉联合基础：先把开发工具用起来

AI 与视觉方向共用一段基础训练。它连接后面的 ROS 2、导航、视觉算法与机器人程序开发。

**学习顺序：** 计算机基础 → Git 与 GitHub → Ubuntu → Python → C++。对应[AI 与视觉联合培训原文](?group=joint)中的五个模块和阶段安排。

## 第一步｜认识电脑与文件

从[计算机基础](?doc=computer)开始，找到自己电脑的 CPU、内存和存储信息，完成文件整理练习。后续下载数据、管理代码和安装依赖都会用到这些操作。

**完成判断：** 能找到系统信息，在文件管理器中整理项目文件，理解文件路径指向什么位置。

原路线视频：[计算机基础 1](https://www.bilibili.com/video/BV15i9UBhEZ2) · [计算机基础 2](https://www.bilibili.com/video/BV1UwPgziE3F)。

## 第二步｜用 Git 管理一个项目

按[Git 与 GitHub](?doc=git)教程完成一次本地提交和远程推送。随后修改同一个文件，再提交第二个版本，观察提交历史的变化。

**动手练习：** 在自己的练习仓库中完成至少两次有清晰说明的提交，用 `git log --oneline` 找到两次修改。

**完成判断：** 能区分工作区、暂存区、本地提交与远程仓库，知道如何查看当前文件变更。

原路线视频：[Git 1](https://www.bilibili.com/video/BV1Y8aL6SEit) · [Git 2](https://www.bilibili.com/video/BV1LwHv6LEYz)。

## 第三步｜使用 Ubuntu 与终端

按照组内环境安排安装或使用 Ubuntu，认识终端、当前工作目录、文件路径和权限。练习 `pwd`、`ls`、`cd`、`mkdir`、`cp`、`mv`，再了解软件包安装和环境变量的基本概念。

**动手练习：** 在自己的练习目录中新建两个文件夹，复制一份文本文件并改名，最后用 `ls` 验证目录结构。

**完成判断：** 能解释绝对路径与相对路径，知道文件权限如何影响读取和执行，并能按组内资料配置开发工具。

原路线视频：[Ubuntu 1](https://www.bilibili.com/video/BV1cq421w72c) · [Ubuntu 2](https://www.bilibili.com/video/BV1Cc41127B9)。

## 第四步｜用 Python 解决一个小问题

掌握变量、数据类型、条件、循环、函数，再练习列表、字典、文件操作和类的基础用法。认识第三方库安装与虚拟环境的意义。

**动手练习：** 编写一个读取文本记录的小脚本，统计行数或某种关键词出现的次数，将结果输出到终端。给脚本添加一个函数，再换一份数据验证结果。

**完成判断：** 能独立运行脚本、修改输入、查看报错并定位到具体代码行。

原路线视频：[Python](https://www.bilibili.com/video/BV1rpWjevEip)。

## 第五步｜掌握 C++ 的常用表达

从变量、流程控制和函数入手，练习指针、引用、类、继承、多态以及 `vector`、`map` 等 STL 容器。

**动手练习：** 定义一个保存机器人目标位置或状态的数据结构，用容器存放多组数据，再编写函数遍历并输出结果。

**完成判断：** 能编译、运行一个多函数的小程序，说明引用与拷贝的差别，知道编译错误和运行结果分别在哪里检查。

原路线视频：[C++](https://www.bilibili.com/video/BV1Dk4y1j7oj)。

## 基础结束后选择方向

- **视觉方向：** 进入[视觉方向学习路径](?doc=path-vision)，继续学习进阶 C++、OpenCV 与视觉算法。
- **AI 方向：** 进入[AI 方向学习路径](?doc=path-ai)，继续学习 ROS 2、哨兵框架与导航模块。

联合培训原文包含各周时间节点与阶段考核，具体安排可在[原始文件](?group=joint)查看。
