# Ubuntu 与终端：认识开发环境
Linux 是操作系统内核，Ubuntu 是基于 Linux 的发行版。AI 与视觉项目常在 Ubuntu 环境中运行工具、编译程序和管理依赖。
## 常用终端命令
以下命令演示目录创建、路径切换和文件查看：
```bash
pwd
mkdir -p ~/tarsgo-practice/data
cd ~/tarsgo-practice
touch data/notes.txt
ls -l data
```
`pwd` 显示当前目录，`cd` 切换目录，`~` 代表当前用户主目录。`ls -l` 可以查看文件的部分权限信息。
## 绝对路径、相对路径与权限
以 `/home/user/work` 开头的是绝对路径；`data/notes.txt` 则相对于当前工作目录。读（r）、写（w）、执行（x）权限决定文件可以怎样使用，目录权限还会影响进入和列举。
## 环境为什么会影响程序运行
同一份代码在不同电脑上可能遇到依赖或版本差异。遇到问题时记录 Ubuntu 版本、工具版本、运行命令和错误信息，再对照项目文档定位。

## 终端为什么能操作文件

在文件管理器中创建文件夹，是通过图形界面发出操作请求；在终端输入 `mkdir`，也是让操作系统执行创建目录的工作。终端不是另一套文件系统，而是同一系统的另一种操作方式。

例如：

```bash
mkdir -p ~/tarsgo-practice/data
cd ~/tarsgo-practice
pwd
ls
```

第一条创建目录，第二条把当前工作目录切换到项目目录，第三条输出当前位置，第四条列出当前内容。

## 路径为什么影响运行结果

若当前目录是 `~/tarsgo-practice`，相对路径 `data/notes.txt` 指向项目里的文件。如果切换到其他位置，同样的文字可能指向另一个位置。

`~` 表示当前用户主目录；`.` 表示当前目录；`..` 表示上级目录。通过这些符号可以构造相对路径。

## 读写执行权限有什么区别

Linux 文件权限常用 `r`、`w`、`x` 表示读取、写入和执行。对于普通文件，读取权限允许查看内容，写入权限允许修改，执行权限控制是否允许把文件当程序执行。

目录上的权限有不同的具体含义，例如进入目录通常涉及执行权限。`ls -l` 可以查看相关信息。

## 同样代码为何有时不能运行

错误可能来自程序自身，也可能来自当前工作目录、依赖版本、环境变量、权限或编译结果。将命令、报错内容和软件版本一并记录，有助于准确定位原因。
