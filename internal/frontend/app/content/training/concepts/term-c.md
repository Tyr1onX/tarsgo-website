# C 语言里的指针、结构体与位运算
电控程序需要处理设备状态、传感器数据和控制命令。C 语言中的这三项能力，正好解决“数据放在哪里、怎样组织、怎样读写”的问题。
## 从一条电机反馈认识结构体
一条反馈包含转速、温度和状态。用结构体可以把它们放在一起：
```c
typedef struct {
    int speed_rpm;
    int temperature_c;
    unsigned char flags;
} MotorFeedback;
MotorFeedback feedback = {120, 35, 0x01};
```
其中 `speed_rpm` 表示每分钟转数。`feedback.flags & 0x01` 用于检查最低位是否置位：这是一种位掩码操作，常见于状态寄存器。
## 指针到底指向什么
变量保存值，指针保存变量所在的内存地址。例如 `MotorFeedback *p = &feedback;`，之后 `p->speed_rpm` 访问的是同一份反馈数据。传递指针时，要先确认它指向的对象仍然有效。
数组越界、未初始化指针和访问已经失效的对象，都可能让程序表现异常。调试重点包括输入数据、内存地址与对象生命周期。

## 一份数据和它所在的位置

先看一个普通变量：

```c
int speed = 86;
```

`speed` 的值是 86。程序运行时，这个变量占据一块内存空间。可以通过 `&speed` 取得它的地址，再把地址保存到指针中：

```c
int *p = &speed;
*p = 100;
```

`p` 是指向整数的指针；`*p` 表示沿着这个地址访问那个整数。修改 `*p` 会让 `speed` 变成 100。这里的 `*` 在声明和访问时含义与上下文有关：声明时用于描述指针类型，表达式中用于解引用。

## 多项数据怎样放在一起

假设电机的转速和温度总是一起传输，用两个毫无关联的变量会难以管理。结构体为一组字段定义共同类型，例如原来的 `MotorFeedback`。

`feedback.speed_rpm` 用点号读取字段；当手里拿的是指针时，使用 `p->speed_rpm` 访问。箭头写法等价于通过指针找到结构体后再取字段。

## 位运算用在哪里

设备状态常用一个字节中的不同位表示开关。例如 `flags = 0x05`，二进制是 `00000101`，第 0 位和第 2 位被置为 1。

```c
unsigned char flags = 0x05;
int bit0 = (flags & 0x01) != 0; // 1
int bit1 = (flags & 0x02) != 0; // 0
```

`&` 是按位与运算，掩码 `0x01` 只保留最低位。位掩码适合表达多个独立的标志；每一位的实际含义要由协议或芯片手册明确规定。

使用指针时必须确保它指向的对象仍然有效，且访问范围正确；无效地址或越界访问会导致错误结果甚至程序崩溃。
