# OpenCV：从像素得到可用信息
相机提供的是一帧帧图像。图像处理首先要解决：程序如何读取图像、哪些像素符合条件、如何从这些像素得到一个区域。
## 图像处理的三个步骤
1. **读取与显示**：确定图像分辨率、通道数和像素类型。
2. **颜色空间与阈值**：把像素转换到适合的表示方式，用规则挑选感兴趣的区域。
3. **轮廓与几何量**：从二值区域中找轮廓，估算面积、边界框和中心位置。
OpenCV 是一套常见的计算机视觉库；灰度、HSV 等颜色空间用于描述像素信息。阈值分割依赖光照条件，需要比较不同输入的结果。

## 像素怎样组成图片

把图片放大到一定程度，可以看到一格格颜色点。每一格就是像素，图像的分辨率表示有多少列和多少行。

一张 640×480 的图片，包含 640 列、480 行像素。程序处理图片时，首先拿到的是像素数据，而不是“桌子”“人”这样的物体名称。

## 灰度和阈值是什么

彩色图像有多个颜色通道。将它转成灰度图后，可以用一个数表示像素亮度。对常见 8 位灰度图，这个数字范围是 0 到 255。

假设某张图片的目标区域较亮，可以设置阈值 120。大于 120 的像素标白色，其他标黑色，从而得到**二值图**。

```python
import cv2

image = cv2.imread("sample.png")
if image is None:
    raise FileNotFoundError("sample.png")
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
_, mask = cv2.threshold(gray, 120, 255, cv2.THRESH_BINARY)
cv2.imwrite("mask.png", mask)
```

## 从像素到区域

二值图可用于提取轮廓。轮廓描述一片区域的边界，后续可计算区域面积、外接矩形或中心位置。

这些结果仍属于图像坐标。要转成真实空间位置，还需要结合相机标定和几何信息。

不同光照会改变像素值，因此阈值 120 并不保证适用于所有图片。
