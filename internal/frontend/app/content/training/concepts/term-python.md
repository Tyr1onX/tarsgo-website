# Python：把重复的处理交给程序
Python 适合快速读取文件、整理数据和调用现有工具。学习时先形成一条完整链路：**输入 → 处理 → 输出**。
## 一个可运行的例子
```python
speeds = [98, 102, 105, 95]
def average(values):
    return sum(values) / len(values)
print(f"平均转速：{average(speeds):.1f}")
```
列表 `speeds` 保存多条数据，函数 `average` 把一段处理逻辑封装起来。列表、字典适合组织不同结构的数据；函数让同一规则可以被重复使用。
## 接下来学习什么
条件和循环用于选择与重复；文件读写让程序处理真实记录；类和对象用于组织较复杂的状态与行为；第三方库提供已有能力。项目依赖应记录清楚，并用虚拟环境隔离不同项目。
## 自己验证
将转速数据放入文本文件，读取并计算平均值，再加入“空文件时给出明确提示”的处理。换一份文件仍能得到正确结果。
