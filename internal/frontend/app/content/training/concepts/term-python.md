# Python：把重复的处理交给程序
Python 适合快速读取文件、整理数据和调用现有工具。学习时先形成一条完整链路：**输入 → 处理 → 输出**。
## 一个可运行的例子
```python
speeds = [98, 102, 105, 95]
def average(values):
    return sum(values) / len(values)
print(f"平均转速：{average(speeds):.1f}")
```
列表 `speeds` 保存多条数据，函数 `average` 把一段处理逻辑封装起来。列表、字典适合组织不同结构的数据；函数让同一规则可以被重复使用。
## 基本语法与项目依赖
条件和循环用于选择与重复；文件读写让程序处理真实记录；类和对象用于组织较复杂的状态与行为；第三方库提供已有能力。项目依赖可以用依赖文件记录，并使用虚拟环境隔离不同项目的第三方库版本。

## 从一行数字开始

在 Python 中，`speed = 86` 表示把整数 86 保存到名字 `speed` 对应的变量中。程序可以使用这个值进行计算：

```python
target = 100
speed = 86
error = target - speed
print(error)  # 14
```

这里的 `=` 是赋值，`-` 是减法，`print` 将结果输出。

## 多个数字为什么需要列表

如果一秒钟内得到多次转速测量，可以把它们放在列表里：

```python
speeds = [98, 102, 105, 95]
print(sum(speeds) / len(speeds))  # 100.0
```

列表让一组相关数据可以被统一处理。函数则用于给重复的计算过程命名，例如：

```python
def average(values):
    return sum(values) / len(values)
```

`def` 定义函数；`values` 是函数参数；`return` 把结果返回给调用位置。

## 真实输入还需要考虑什么

如果列表为空，`len(values)` 等于 0，直接计算平均值会触发除零错误。把数据来自文件、用户或传感器时，程序需要先确认输入格式与条件。

文件读取可以由 `pathlib.Path` 完成；第三方库通常安装在与项目对应的 Python 环境中。虚拟环境帮助多个项目使用不同的依赖版本，避免修改一个项目的依赖影响另一个项目。
