# 机械方向：一个旋转结构怎样设计出来

想让一个机器人部件绕着轴转动，需要的不只是“画一根轴”。轴由什么支撑？电机的转动怎样传过去？结构是否足够牢固？零件能不能加工出来？装好后有没有空间拆卸？

这些问题可以从一个小装配体开始：**底座、支架、轴承、转轴和电机传动**。

## 第一步：从尺寸开始理解三维建模

在 SolidWorks 中，最容易看到的是零件的三维外形。但可靠的模型不是随手画出来的形状，它需要可以修改的尺寸和几何关系。

例如，一个支架底部有两个安装孔。两个孔之间有固定距离，孔径也有明确数值。可以先在二维草图上画出轮廓与孔的位置，再通过拉伸生成三维形状。

这里有三项不同概念：

- **草图**：表示几何轮廓，例如线段、圆与圆弧。
- **尺寸**：规定长度、孔径或角度。
- **约束**：规定几何关系，例如两条线平行、一个圆与另一个圆同心。

如果改变安装孔间距，相关草图关系应当随之更新。这个过程叫作**参数化建模**。它帮助设计者保留尺寸之间的逻辑关系，而不是每改一次就重画整个零件。

[CAD 建模与装配约束](?doc=term-cad)解释零件、特征和装配体的区别。

## 第二步：几个零件怎样组成一个机构

一根轴、一只轴承和一个支架分别是零件。把它们按实际位置放在一起，并规定谁可以相对谁运动，就形成了**装配体**。

例如，支架固定在底座上，轴承安装在支架孔中，轴穿过轴承。支架相对底座应保持固定，而轴通常需要保留绕轴线转动的自由度。

**自由度**表示一个物体能够独立运动的方式。零件之间的配合会限制其中某些自由度。若把本应转动的轴完全锁死，模型可能在外观上完整，但已失去功能。

实际装配还要检查三个问题：连接件有无空间安装、运动时是否与周围零件干涉、维护时能否拆卸。

## 第三步：电机的运动如何传到轴上

电机提供转动，机构要把这种运动传到目标部件。齿轮、同步带、联轴器等是常见的传动方式。

先看一个理想的减速传动例子：

```text
电机输入转速：3000 rpm
传动比：3:1（输入转三圈，输出转一圈）
理想输出转速：1000 rpm
```

转速降低后，输出的理想转矩往往会相应增大，但实际机构还有效率损失，不能简单把所有计算结果当成实测值。

这里出现几个重要概念：

- **转速**：单位时间内转动多少圈。
- **转矩**：使物体产生旋转的力矩。
- **轴**：传递旋转与转矩的机械零件。
- **轴承**：支撑旋转部件并承受相应载荷的机械元件。
- **传动比**：输入和输出转速之间的比例关系。

[轴系与传动](?doc=term-mechanism)进一步介绍支撑、轴承和运动链。机械设计通常要同时考虑速度、负载、支撑、空间与可维护性。

## 第四步：同一个支架为什么可以用不同材料

同一个形状可能采用 3D 打印塑料、铝合金、碳纤维板或其他材料加工。选材并不只看重量，还取决于它实际承受怎样的力。

例如，一个支架受力后产生微小变形。如果变形影响机构的安装精度，即使它没有断裂，仍可能无法正常工作。

这里需要区分：

- **强度**：结构抵抗失效或破坏的能力。
- **刚度**：结构抵抗弹性变形的能力。
- **重量**：影响机器人总质量与运动负担。
- **工艺**：决定这个形状如何成为实物。

3D 打印常用于快速验证形状和装配，CNC 加工适用于不同的尺寸、材料与精度需求，板材加工则适合特定结构形式。不同工艺对最小特征、孔位、材料和装夹方式都有要求。

[材料与加工](?doc=term-materials)解释铝合金、板材、3D 打印和 CNC 的常见差别。真实设计还需结合加工条件、成本和标准件的供应情况。

## 第五步：从零件走向系统方案

机器人通常包含底盘、云台、发射与输弹等子系统。单个零件合理，并不代表整套系统合理。例如把云台结构做得更大，可能增加刚度，也会占用其他模块的空间。

设计方案通常从几个可以明确的问题出发：

| 问题 | 对应的工程条件 |
| --- | --- |
| 要完成什么运动？ | 运动范围、速度、转矩 |
| 需要承受什么作用？ | 力、冲击、振动、载荷 |
| 允许占用多少空间？ | 外形尺寸、安装孔和线束位置 |
| 怎样制造和维护？ | 材料、工艺、紧固件与拆卸空间 |

例如，对同一个支架可以提出两个方案：方案 A 加厚材料，方案 B 增加局部加强筋。二者都可能提高刚度，但重量、成本、加工方式及应力分布不同。

方案比较的依据来自实际需求，而不是图纸看上去更复杂或更精致。

## 第六步：仿真告诉我们什么

模型在 SolidWorks 中能正确装配，只说明几何关系满足设计约束。结构受力以后会怎样，还需要分析。

**静力学仿真**可以在指定材料、载荷和固定条件下，估计结构的应力与变形。有限元分析（FEA）通常将连续结构划分为许多单元，利用数值方法近似求解。

以支架为例，固定底部安装孔附近的位置，在上方施加代表负载的力，软件就会计算一个相应的变形与应力结果。

但这些结果依赖输入条件：

- 载荷方向与大小是否贴近真实工况；
- 约束是否反映实际的连接方式；
- 材料参数是否正确；
- 网格尺寸与质量是否足够支持所需结论。

[静力学仿真、强度与刚度](?doc=term-fea)详细解释这些概念。仿真给出的是在所设模型条件下的计算结果，实际加工和测试仍是重要验证环节。

## 第七步：设计为什么需要迭代

假设第一版支架加工后发现与附近线束干涉。这说明模型的几何尺寸可能正确，但系统空间约束考虑不足。

第二版修改支架外形后，需要重新检查装配干涉、载荷路径、连接强度和加工方式。保存第一版的图纸、修改原因和测试结果，才能判断改动真正解决了什么。

完整的机械工作链路是：

```text
功能需求 → 方案与尺寸 → 零件建模 → 装配
    ↑                              ↓
迭代与复测 ← 加工测试 ← 材料与工艺检查
```

从一个可转动的小装配体，到完整机器人的结构设计，本质上都在处理同一组问题：运动、受力、空间、制造和验证。
