# 计算机基础

## 计算机的硬件组成

计算机通过处理器执行程序，使用内存保存运行时的数据，通过存储设备长期保留文件。硬件之间由主板、总线和接口连接，协同完成输入、处理与输出。

| 名称 | 主要作用 | 典型应用 |
| --- | --- | --- |
| CPU（处理器） | 执行程序指令、进行计算 | 编译代码、运行仿真和计算任务时 |
| 内存（RAM） | 程序运行时暂时使用的空间 | 同时打开很多软件、运行大程序时 |
| 硬盘 / 固态硬盘 | 长期保存系统、程序与文件 | 安装软件、下载资料、保存项目时 |
| GPU（图形处理器） | 处理图形和适合并行计算的任务 | 图像处理、部分 AI 训练和推理时 |
| 主板 | 连接各个硬件并让它们协同工作的电路板 | 认识整机组成和接口时 |

程序启动时，操作系统通常从存储设备读取程序文件，把运行所需的代码和数据放入内存，CPU 再执行指令。内存与硬盘因此承担不同职责：内存主要服务于运行过程，硬盘主要服务于长期存储。

各系统查看硬件信息的位置：

- **Windows**：设置 → 系统 → 系统信息；任务管理器 → 性能，显示 CPU、内存和磁盘使用情况。
- **macOS**：苹果菜单 → 关于本机，显示芯片与内存；系统设置 → 通用 → 储存空间，显示磁盘使用情况。
- **Ubuntu**：设置 → 关于，显示设备与系统信息；磁盘工具与文件管理器可查看存储空间。

## 操作系统、文件与目录

Windows、macOS、Ubuntu 都是操作系统。它们负责管理硬件、文件和应用程序。编辑器、浏览器、代码工具则是运行在操作系统上的软件。

目录可以包含其他目录与文件，例如：

```text
tarsgo-practice/
├── notes.txt
└── materials/
    └── notes-backup.txt
```

`notes.txt` 与 `materials/notes-backup.txt` 位于不同目录。文件路径用来标识文件的位置；绝对路径从系统约定的起点开始，相对路径以当前工作目录为起点。

文件扩展名用于标识常见格式，例如 `.txt` 通常表示纯文本。扩展名与文件内部格式并非一回事，直接修改后缀不会自动转换文件内容。

## 软件安装、版本与依赖

应用程序与操作系统共同构成软件环境。Git、编辑器、编译器和运行时工具可能依赖不同版本的系统组件或第三方库。

软件包应与操作系统和处理器架构匹配。版本号用于区分发布内容；依赖是软件运行或构建时需要的其他程序与库。包管理器可以管理安装、更新与卸载，并协助处理部分依赖关系。

常见软件分发方式包括官方安装包、操作系统应用商店和包管理器。[Git](?doc=git) 是用于版本管理的开发工具。

## 域名、网络与网页访问

浏览器访问 `example.com` 时，需要经过几项基本环节：

**连接网络 → DNS 将域名解析为地址 → 浏览器通过 HTTPS 与网站建立连接 → 接收并显示页面。**

其中，DNS 的作用是帮助把域名解析成网络地址；HTTPS 则为浏览器与网站之间的通信提供加密和身份验证。

访问网页时，域名用于标识网站，DNS 负责域名解析，HTTPS 在加密连接上交换网页请求与响应。网络故障可根据影响范围区分：

- **所有网站都无法访问**：检查 Wi-Fi、网线和系统网络连接。
- **只有一个网站无法访问**：核对域名，再观察该站点是否出现故障或解析问题。
- **浏览器显示证书警告**：先核对地址和证书信息，确认网站身份后再继续。
