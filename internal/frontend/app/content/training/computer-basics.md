# 计算机基础：先认识自己的电脑

**适用方向：** AI、视觉联合基础培训；也适合第一次接触开发环境的新人。

**学完后能做什么：** 找到电脑的硬件与系统信息，整理项目文件，并根据网络连接现象开始排查问题。

从手边的电脑开始。完成本篇后，你会得到一份自己的电脑信息记录和整理好的练习目录。

## 1. 先看看你正在使用什么

先认识五个最常接触的硬件部件，以及它们在运行程序时承担的工作：

| 名称 | 可以把它理解成 | 什么时候需要关心 |
| --- | --- | --- |
| CPU（处理器） | 执行程序指令、进行计算 | 编译代码、运行仿真和计算任务时 |
| 内存（RAM） | 程序运行时暂时使用的空间 | 同时打开很多软件、运行大程序时 |
| 硬盘 / 固态硬盘 | 长期保存系统、程序与文件 | 安装软件、下载资料、保存项目时 |
| GPU（图形处理器） | 处理图形和适合并行计算的任务 | 图像处理、部分 AI 训练和推理时 |
| 主板 | 连接各个硬件并让它们协同工作的电路板 | 认识整机组成和接口时 |

**动手操作：** 查找自己电脑的处理器、内存与磁盘容量，把结果记到 `notes.txt`，再解释各自承担什么工作。

- **Windows**：打开「设置 → 系统 → 系统信息」查看处理器与内存；打开任务管理器的「性能」页查看 CPU、内存和磁盘使用情况。
- **macOS**：打开苹果菜单中的「关于本机」查看芯片与内存；在「系统设置 → 通用 → 储存空间」查看磁盘使用情况。
- **Ubuntu**：在系统「设置 → 关于」查看设备与系统信息；磁盘容量可以在磁盘管理工具或文件管理器里查看。

**完成判断：** 能解释内存与磁盘容量的区别，并找到查看 CPU、内存与磁盘使用情况的位置。

## 2. 认识操作系统、软件和文件

Windows、macOS、Ubuntu 都是操作系统。它们负责管理硬件、文件和应用程序。编辑器、浏览器、代码工具则是运行在操作系统上的软件。

先在文件管理器中完成下面的小练习：

1. 在自己容易找到的位置（例如「文档」文件夹）创建一个名为 `tarsgo-practice` 的文件夹。
2. 在里面创建 `notes.txt`，写下你的操作系统名称、CPU 和内存信息，并保存。
3. 复制 `notes.txt`，把副本重命名为 `notes-backup.txt`。
4. 新建 `materials` 文件夹，把 `notes-backup.txt` 移进去。
5. 重新打开两个文件，确认内容还在。

完成后你应该有这样的结构：

```text
tarsgo-practice/
├── notes.txt
└── materials/
    └── notes-backup.txt
```

文件扩展名能帮助系统识别文件类型，例如 `.txt` 表示纯文本。打开文件管理器的「显示文件扩展名」选项，核对两个文件的实际后缀。修改文件格式时，要使用对应软件的导出或转换功能。

## 3. 软件安装之前要知道什么

Git、代码编辑器和编译器都有各自的安装方式。认识官方安装来源和版本信息，是搭建开发环境的第一步。

安装软件时依次确认：**下载来源、操作系统兼容性、软件版本**。优先使用官方安装包或官方推荐的包管理方式。

**动手操作：** 在应用列表中找到已经安装的浏览器或编辑器，查看它的版本号与安装位置，再访问该软件的官方网站，找到下载和更新说明。

**完成判断：** 能找到软件的版本、官方文档和卸载入口，知道如何选择适合自己系统的安装包。

## 4. 打开网页时发生了什么

浏览器访问 `example.com` 时，需要经过几项基本环节：

**连接网络 → DNS 将域名解析为地址 → 浏览器通过 HTTPS 与网站建立连接 → 接收并显示页面。**

其中，DNS 的作用是帮助把域名解析成网络地址；HTTPS 则为浏览器与网站之间的通信提供加密和身份验证。

**动手操作：** 在浏览器中打开 `https://example.com`，观察地址栏中的域名和 HTTPS 标识。再打开另一个熟悉的网站，比较两次访问的结果。

如果网页打不开，先看设备是否已连接网络，再试另一个可靠的网站：

- **所有网站都无法访问**：检查 Wi-Fi、网线和系统网络连接。
- **只有一个网站无法访问**：核对域名，再观察该站点是否出现故障或解析问题。
- **浏览器显示证书警告**：先核对地址和证书信息，确认网站身份后再继续。

**完成判断：** 能区分设备连接异常、域名访问异常和 HTTPS 证书提示，并知道分别从哪里开始排查。

## 5. 用自己的话复述一次

回到刚才的 `notes.txt`，再补上四行：

1. 我的电脑使用什么操作系统？
2. CPU、内存和硬盘分别负责什么？
3. 我把备份文件放在了哪个文件夹？
4. 如果某个网页打不开，我准备先检查什么？

**完成判断：** `notes.txt` 中记录了电脑配置、文件整理结果和网络排查顺序，你能在自己的电脑上重复完成这些操作。
