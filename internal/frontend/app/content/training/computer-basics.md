# 计算机基础：先认识自己的电脑

**适用方向：** AI、视觉的联合基础培训明确包含计算机通识；其他第一次接触电脑开发环境的同学也可以按需阅读。

**完成目标：** 找到自己电脑的硬件与系统信息；分清文件、文件夹和程序；亲手整理一份学习文件；能够初步判断网络问题发生在哪一环。

> 不需要购买设备、安装其他系统或提交截图。下面的操作用你现在正在使用的电脑即可完成。

## 1. 先看看你正在使用什么

电脑里有很多零件，你不用一开始就记住所有型号。先理解几样最常碰到的东西：

| 名称 | 可以把它理解成 | 什么时候需要关心 |
| --- | --- | --- |
| CPU（处理器） | 执行程序指令、进行计算 | 编译代码、运行仿真和计算任务时 |
| 内存（RAM） | 程序运行时暂时使用的空间 | 同时打开很多软件、运行大程序时 |
| 硬盘 / 固态硬盘 | 长期保存系统、程序与文件 | 安装软件、下载资料、保存项目时 |
| GPU（图形处理器） | 处理图形和适合并行计算的任务 | 图像处理、部分 AI 训练和推理时 |
| 主板 | 连接各个硬件并让它们协同工作的电路板 | 认识整机组成和接口时 |

**现在动手：** 找到自己电脑的 CPU、内存和磁盘容量，并试着用自己的话描述它们有什么区别。

- **Windows**：打开「设置 → 系统 → 系统信息」查看处理器与内存；打开任务管理器的「性能」页查看 CPU、内存和磁盘使用情况。
- **macOS**：打开苹果菜单中的「关于本机」查看芯片与内存；在「系统设置 → 通用 → 储存空间」查看磁盘使用情况。
- **Ubuntu**：在系统「设置 → 关于」查看设备与系统信息；磁盘容量可以在磁盘管理工具或文件管理器里查看。

**检查一下：** 你能否说清楚“16 GB 内存”和“512 GB 硬盘”为什么不是同一件事？如果电脑运行变慢，你知道去哪里看资源使用情况了吗？

## 2. 认识操作系统、软件和文件

Windows、macOS、Ubuntu 都是操作系统。它们负责管理硬件、文件和应用程序。编辑器、浏览器、代码工具则是运行在操作系统上的软件。

先在文件管理器中完成下面的小练习：

1. 在自己容易找到的位置（例如「文档」文件夹）创建一个名为 `tarsgo-practice` 的文件夹。
2. 在里面创建 `notes.txt`，写下你的操作系统名称、CPU 和内存信息，并保存。
3. 复制 `notes.txt`，把副本重命名为 `notes-backup.txt`。
4. 新建 `materials` 文件夹，把 `notes-backup.txt` 移进去。
5. 重新打开两个文件，确认内容还在。

完成后你应该有这样的结构：

```text
tarsgo-practice/
├── notes.txt
└── materials/
    └── notes-backup.txt
```

这里顺便记住：**文件名不等于文件类型。** `.txt` 是文件扩展名，常用来标识纯文本。为了避免误操作，可以在文件管理器里开启显示扩展名。不要因为改了后缀就认为文件已经转换了格式。

## 3. 软件安装之前要知道什么

以后你会接触 Git、开发编辑器、编译器和各种专业工具。它们不一定使用相同的安装方法。

安装前先确认三件事：这是软件的**官方来源**吗？版本适合当前操作系统吗？自己是否真的需要它？

目前不需要额外安装任何软件。如果要安装，请优先看官方提供的安装与卸载说明；不要把网上不明来源的安装包、破解程序或命令直接运行在自己的电脑上。

你可以打开电脑的应用列表，找到一个已经安装的软件，看看在哪里查看版本信息、怎样正常退出程序；这也是认识操作系统的一部分。

## 4. 打开网页时发生了什么

使用浏览器时，你输入的是域名（例如 `example.com`），不是网线里的直接地址。通常会经过这些环节：

**电脑连接 Wi-Fi 或网线 → 接入局域网 → 通过路由器等设备访问互联网 → 把域名解析成网络地址 → 浏览器与网站通信。**

其中，DNS 的作用是帮助把域名解析成网络地址；HTTPS 则为浏览器与网站之间的通信提供加密和身份验证。

**现在动手：** 在浏览器中打开 `https://example.com`。如果能够加载页面，说明这次访问需要的基本网络环节已经工作。

如果网页打不开，先看设备是否已连接网络，再试另一个可靠的网站：

- **所有网站都打不开**：先检查 Wi-Fi、网线或网络连接状态。
- **只有一个网站打不开**：可能与该网站、域名解析或访问路径有关，不能直接认定是电脑坏了。
- **浏览器提示证书问题**：不要随意跳过安全警告，先确认地址是否正确。

这一步不要求掌握网络协议的全部细节，只要能区分“本机没有联网”和“某个网站访问失败”，就已经迈出了第一步。

## 5. 用自己的话复述一次

回到刚才的 `notes.txt`，再补上四行：

1. 我的电脑使用什么操作系统？
2. CPU、内存和硬盘分别负责什么？
3. 我把备份文件放在了哪个文件夹？
4. 如果某个网页打不开，我准备先检查什么？

不必追求标准答案。只要你能自己找到信息、完成文件操作、解释大致原因，就达到了这次练习的目的。不需要上传或打卡。
